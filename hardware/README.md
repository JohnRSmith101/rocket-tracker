# Hardware

License: CC BY-SA 4.0.

- `kicad/`: KiCad projects for the Gimbal Controller circuit boards (**Box** and **Lid**). Each folder has the KiCad project, schematic and PCB files, a picture, and a zip of the Gerber and drill files for ordering boards.
- `3d-printing/`: one folder per part, each with an STL file and a preview picture. Print in PETG. The parts were designed in the Morphi app (iPad) and sliced in Ultimaker Cura for an Ender 3 printer. See the Build Book, Appendix A, for the parts list and photos.

The Build Book has the wiring, the complete parts list, and assembly instructions.
